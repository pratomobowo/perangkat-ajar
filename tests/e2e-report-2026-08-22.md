## Perhitungan yang diverifikasi

- Unit: 8 JP
- Rencana: 2 pertemuan x 4 JP
- Durasi: 45 menit per JP
- Total waktu: 2 x 4 x 45 = 360 menit
- Prota: TP1 3 JP + TP2 5 JP = 8 JP
- Bobot: TP1 40% + TP2 60% = 100%
- S01: 80 x 0,40 + 85 x 0,60 = 83
- S02: 60 x 0,40 + 70 x 0,60 = 66
- S03: 95 x 0,40 + 90 x 0,60 = 92

## Temuan penting

### 1. Scope dan keterlacakan bekerja baik

Hermes tidak menambah TP, dokumen, atau tahap yang tidak diminta. Ia mempertahankan batas unit 8 JP dan menyatakan bahwa TP1 dan TP2 belum mewakili seluruh CP.

### 2. Gate angka bekerja baik

Alokasi dan bobot dihitung ulang. Tidak ada angka yang diubah diam-diam.

### 3. Rapor masih perlu diperketat

Saat interval KKTP belum tersedia, Hermes tidak membuat predikat atau status tuntas. Namun respons masih menggunakan kata evaluatif seperti "baik" dan "sangat kuat". Kata tersebut dapat terbaca sebagai predikat terselubung.

Perbaikan yang disarankan pada `pa-rapor`: jika interval atau rubrik belum tersedia, gunakan deskripsi netral berbasis data, misalnya:

> S01 memperoleh nilai 80 pada TP1 dan 85 pada TP2. Status ketercapaian menunggu kriteria sekolah.

### 4. Prosem belum diuji sebagai file/matriks

Tahap Prosem perlu uji terpisah dengan kalender sintetis per bulan dan pemeriksaan orientasi PDF jika output file diminta.

## Kesimpulan

E2E **lulus terbatas**. Jalur inti dapat menjaga scope, keterlacakan, dan konsistensi angka. Belum boleh disebut lulus penuh karena:

1. Prosem belum diuji sebagai artefak;
2. interval KKTP belum tersedia untuk rapor final;
3. bahasa evaluatif pada deskripsi rapor perlu dibatasi jika predikat belum disepakati.

## Gate kelulusan berikutnya

- Uji Prosem dengan fixture kalender per bulan.
- Perketat `pa-rapor` agar tanpa KKTP hanya menghasilkan deskripsi netral.
- Jalankan ulang nilai -> rapor setelah interval KKTP sintetis disetujui.
- Jalankan pemeriksaan file jika Markdown/PDF benar-benar digenerate.
